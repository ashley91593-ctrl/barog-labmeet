# 바로그의원 유성점 × LABMEET

병원 소개, 진료 철학, 랩미 참가자 제휴 혜택을 안내하는 모바일 대응 정적 상세페이지입니다.

## 실행

별도의 빌드나 패키지 설치가 필요하지 않습니다.

```sh
python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 엽니다.

## 구성

- `index.html`: HTML 및 반응형 CSS
- `skin-editorial.png`: 스킨보톡스 카드 장식 배경
- `pink-editorial.png`: 핑크필 관리 카드 장식 배경

모바일에서도 두 혜택 카드가 가로로 배치됩니다. 한글 시술명은 이미지가 아닌 HTML 텍스트입니다.

## 외부 리소스와 링크

로비 사진은 바로그의원 유성점 공식 홈페이지의 CDN 이미지를 참조합니다. 폰트는 Google Fonts에서 불러옵니다. 카드 배경 두 장은 AI로 생성한 추상 장식 이미지이며 실제 제품 사진이 아닙니다.

네이버 지도, 카카오톡 채널, 공식 홈페이지, 인스타그램 연결은 `index.html`에서 수정할 수 있습니다.

## 배포

정적 호스팅의 게시 디렉터리를 저장소 루트로 지정합니다. GitHub 저장소에 소스를 업로드하는 것과 웹사이트 공개 배포는 별도입니다.

## 운영 확인 사항

행사 기간, 부가세 기준, 중복 적용 조건 및 광고 문구의 최종 검토는 운영 주체가 확인해야 합니다.
